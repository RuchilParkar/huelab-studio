# huelabstudio — Advanced Color Intelligence & Palette Studio

<div align="center">
  
> A precision color workspace for generating, exploring, editing and exporting color palettes, gradients and design tokens.

HueLab is a dark, design-focused color toolkit built for designers, frontend developers and creative professionals. It brings color palette generation, harmony exploration, color conversion, contrast analysis and gradient creation into a unified workspace.

Built with a focus on precision, functional minimalism and a color-first interface.

## Features

- **Palette Generator** — Generate and explore color combinations.
- **Color Locking** — Lock individual colors while regenerating the rest of a palette.
- **Color Editing** — Fine-tune individual colors.
- **Color Harmony** — Explore harmonious color combinations.
- **Color Converter** — Convert colors across HEX, RGB, HSL and other supported formats.
- **Gradient Studio** — Create, customize and export CSS gradients.
- **Contrast Checker** — Evaluate contrast ratios and accessibility.
- **Image Color Extractor** — Extract color palettes from images.
- **Favorites** — Save palettes for later.
- **Palette History** — Revisit previously generated palettes.
- **Explore** — Discover curated color combinations.
- **Export Tools** — Export palettes in supported formats.
- **Component Preview** — Preview color tokens across interface components.
- **Keyboard Shortcuts** — Work with keyboard-accessible controls.

## Design Philosophy

**Quiet Chrome, Vivid Pigment.**

HueLab follows a restrained visual approach where the interface stays quiet and the colors take center stage.

- Dark graphite surfaces
- Subtle borders and precise spacing
- Monospaced color coordinates
- Minimal visual distractions
- Purposeful interactions
- Responsive layouts

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/RuchilParkar/huelab-studio.git)
cd huelab-studio
npm install
```

### Development

```bash
npm run dev
```

### Testing

```bash
npm run test
```

### Production Build

```bash
npm run build
```
